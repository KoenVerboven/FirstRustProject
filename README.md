Use Terminal window Cmd to type following commands:

## Check Rust version
```
rustc --version
```

## Create new Project

In Visual Studio Code :

Menu - Choose Open Folder, to set the destination folder

Type in Terminal window  :

```
cargo new ProjectName
```
Cargo = package manager.

More info about Cargo : https://doc.rust-lang.org/cargo/commands/cargo.html

## Build Project
```
cargo build
```

## Run project
```
cargo run
```

Extra info about installation Rust:
https://doc.rust-lang.org/book/ch01-01-installation.html
